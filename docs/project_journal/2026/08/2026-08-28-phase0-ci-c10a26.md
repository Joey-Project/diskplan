# Phase 0 Public macOS CI

## Summary

- 为 shared foundation 建立 public GitHub-hosted macOS CI。
- macOS 26 Apple Silicon 是 required release gate；macOS 14 deployment compatibility 独立为 non-blocking best-effort evidence。

## Current State

- Required job 使用 GitHub 官方 `macos-26` M1 label，并显式选择 Xcode 26.6。
- Required job 覆盖 Swift build/test、Rust locked fmt/check/test/clippy、Protobuf 与 canonical drift、真实 Swift/Rust process tests、deployment target、workflow/shell static checks 和 project journal validation。
- CI actions 使用 immutable commit SHA；Rust、Protobuf、SwiftProtobuf generator、ShellCheck 与 actionlint 使用 version/revision/checksum pin。
- Cache 只包含 Cargo 与 SwiftPM dependency downloads；build outputs、generated sources、test outputs 和 tools 不进入 cache。
- 失败 artifact 只包含小于 16 KiB 的 allowlisted runner/toolchain manifest，保留七天。
